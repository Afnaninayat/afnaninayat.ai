# Afnan Inayat — Professional Developer Portfolio

> **Software Developer • Flutter Developer • React Developer • AI & Computer Vision • Digital Design & Verification**

A modern, high-performance, responsive personal portfolio website built with **React**, **Vite**, **Tailwind CSS**, **Framer Motion**, and **Lucide Icons**. Designed using the refined dark technical **Batsman Pro** visual identity (`#0B0F0E` background, `#B6FF00` signature lime accent).

---

## ⚡ Tech Stack

* **Core**: React 18, JavaScript (ES6+), Vite
* **Styling**: Tailwind CSS, Custom Glassmorphism, CSS Modules
* **Animations**: Framer Motion
* **Icons**: Lucide React
* **Typography**: Inter & Outfit (Google Fonts)

---

1. **[Batsman Pro](https://github.com/afnaninayat/batsman-pro)** — AI-driven cricket analysis platform utilizing video-based computer vision (YOLO, OpenCV), human skeletal pose tracking, and real-time biomechanics evaluation.

## 🛠️ Local Setup & Development

Clone the repository and run locally:

```bash
# Clone the repository
git clone git@github.com:Afnaninayat/afnaninayat.com.git
cd afnaninayat.com

# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
