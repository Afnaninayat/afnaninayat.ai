## ⚡ Dual-Track Information Architecture

### 1. 🔬 Track 1: Engineering & Technology
* **Digital IC Design & Verification Journey**: 6-stage structured progression from digital logic foundations, synthesizable FSMs in Verilog, object-oriented SystemVerilog verification, AMBA protocols (APB, AHB, AXI), UVM testbenches with 100% functional coverage, and FPGA prototyping to ASIC RTL-to-GDS physical design awareness.
* **Flagship FYP Case Study**: **[Batsman Pro](https://github.com/afnaninayat/batsman-pro)** — AI-driven cricket video analytics platform uniting YOLO object detection, OpenCV video parsing, skeletal pose estimation, and biomechanics tracking.
* **Key Projects**:
  1. **RV32I RISC-V Processor Core**: 5-stage pipelined datapath with hazard forwarding.
  2. **AMBA Protocol Suite**: APB, AHB, and AXI interconnects with SVA assertions.
  3. **UVM Constrained-Random Suite**: Reusable testbenches with scoreboard validation.
  4. **CPU Cache Simulator**: Object-oriented C++ cache hierarchy (Direct, 2/4-Way, LRU).
  5. **Synthesizable UART Controller**: 16x oversampling baud rate generator and FIFO.
  6. **FPGA VGA Video Engine**: 640x480 @ 60Hz timing generator.
  7. **Flutter Mobile & Web Suite**: Cross-platform client applications.

  * Luxury branding & logo design

## 🚀 Local Setup & Development

```bash
# Clone the repository
git clone https://github.com/Afnaninayat/afnaninayat.ai.git
cd afnaninayat.ai

# Install dependencies
npm install

# Start local dev server
npm run dev

# Build production bundle
npm run build
```
